## 📖 The Synopsis (About)
This isn't just another generic template. This is a pixel-perfect, highly responsive replica of the Netflix landing page built from absolute scratch. From the signature dark mode overlay to the flawlessly positioned background videos inside device mockups, every detail is carefully crafted using vanilla CSS flexbox, grid, and media queries. 

**Genres:** `Frontend Development`, `UI/UX Clone`, `Responsive Web Design`  
**This repo is:** `Clean`, `Lightweight`, `Mobile-First`

## 📺 Episodes (Features)

*   **S01 E01: "The Responsive Awakening"**  
    The layout dynamically shifts and adapts from the smallest mobile screens to ultra-wide desktop monitors without breaking a sweat.
*   **S01 E02: "The Flexbox Mystery"**  
    Advanced use of CSS Flexbox to align navbar items, center the hero banner, and perfectly space out the TV/Mobile feature sections.
*   **S01 E03: "The Media Illusion"**  
    Embedded video files auto-playing seamlessly inside transparent PNG mockups of TVs and Apple devices.
*   **S01 E04: "The Accordion"**  
    A sleek, hover-animated FAQ section crafted purely with CSS transitions.
